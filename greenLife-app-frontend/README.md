## Projeto greenLife - Frontend

Este é o projeto de front-end do sistema greenLife, desenvolvido como parte da Atividade Prática - Aula 01.

Tecnologias utilizadas
- Vue 3
- Vite
- Vue Router
- Pinia
- Axios

 Como rodar o projeto
 Certifique-se de ter o Node.js instalado.
 Instale as dependências:

   npm install
   Inicie o servidor de desenvolvimento:

   npm run dev
   Acesse em: http://localhost:5173
